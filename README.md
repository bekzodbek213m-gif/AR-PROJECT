# AR Mebel — IKEA Place'ga o'xshash AR ilova (Android, ARCore)

Texnologiyalar: Kotlin, Google ARCore, OpenGL ES 2.0, GitHub Actions.

Funksiyalar: kamera, gorizontal sirt aniqlash, 10 ta 3D-model katalogi, joylashtirish,
masshtablash (ikki barmoq), burilish (⟲ ⟳), ko'chirish (surish), bir nechta obyekt,
o'chirish/tozalash, skrinshot (Pictures/ARMebel).

## APK olish
1. GitHub'da yangi repo oching va shu papka ichidagi hamma narsani yuklang (`.github` papkasi bilan).
2. Repo'da **Actions → Build APK → Run workflow** (yoki `main` ga push qiling).
3. Tugagach (3–5 daqiqa) run sahifasining pastidagi **Artifacts → ARMebel-apk** ni yuklab oling.
4. Zip ichidagi `app-debug.apk` ni ARCore qo'llab-quvvatlaydigan Android telefonga o'rnating.
